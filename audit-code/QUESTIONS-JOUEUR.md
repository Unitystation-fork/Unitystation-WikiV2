# Questions pour un joueur

Ce que le code du jeu ne permet pas de trancher, après 3 passes d'audit. Chaque question se tranche en une partie (ou par une règle du serveur). **(C)** = règle de serveur, pas dans le code ; **(D)** = comportement en partie, le code existe mais seul un essai le confirme.

Réponds simplement oui / non (et un mot si c'est différent) en face de chaque question : on corrigera la page du wiki en conséquence.
