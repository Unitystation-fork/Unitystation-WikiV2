# Генетик

Генетик также относится к **Научному отделу**: обычно за ним присматривает Директор по исследованиям, потому что у Главного врача, как правило, слишком много дел. Он работает рядом с клонирующей камерой, обычно в медотсеке; на некоторых картах у него есть своя лаборатория в научном отделе.
